# Oficina XML

Aplicativo para organizar cadastros e simular documentos de transporte: NF-e, CT-e, CIOT, MDF-e e NFS-e.

## Baixar para Windows

**[Baixar Oficina XML Completo](https://github.com/Soares007/oficina-xml-downloads/releases/latest/download/Oficina-XML-Completo.exe)**

[Ver todas as versões](https://github.com/Soares007/oficina-xml-downloads/releases)

Requer Windows 10 atualizado ou Windows 11 de 64 bits. Abra o executável com dois cliques. Não é necessário instalar Python ou WebView2 separadamente. Na primeira abertura, aguarde a preparação automática dos componentes.

Os documentos são simulações, sem validade fiscal. Consultas de CEP, CNPJ, municípios, mapas, monitor SEFAZ e atualizações exigem internet.

Cadastros locais ficam em `%LOCALAPPDATA%\Oficina XML\perfil`. Dados de um navegador usado anteriormente não são transferidos automaticamente. Para fazer uma cópia de segurança, feche o aplicativo e copie a pasta `%LOCALAPPDATA%\Oficina XML`. O uso do banco compartilhado depende de uma conta autorizada.

Este repositório distribui o executável. O desenvolvimento é mantido em um repositório privado. Cada publicação preserva as versões anteriores e atualiza o link de download acima.

## Conferir o download

Cada versão inclui `SHA256SUMS.txt`, com o hash do executável. O aplicativo ainda não possui assinatura digital de desenvolvedor.

## Atualizar

Feche o aplicativo e baixe novamente pelo link acima. Substitua o executável anterior; mantenha a pasta de dados em `%LOCALAPPDATA%\Oficina XML`. Não é necessário excluir os cadastros.
